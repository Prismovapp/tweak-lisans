# Ayar lisans iptal listesi

Bu depo sadece **Ayar** uygulamasının imzalı lisans iptal listesini (`revoked.txt`) yayınlar.

- Listede yalnızca iptal edilen lisansların rastgele kimlikleri bulunur; isim, e-posta veya cihaz bilgisi yoktur.
- Liste geliştiricinin gizli anahtarıyla imzalıdır. Ayar imzası doğrulanmayan listeyi kabul etmez; bu yüzden liste başkası tarafından değiştirilemez.
- Bu dosyayı elle düzenlemeyin; Lisans Yöneticisi ile güncellenir.
